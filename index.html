Isometric Cloud Editor

An editor for cloud and network diagrams in isometric view. Edit the drawing or its YAML text, and switch between 3D and 2D. Everything runs in this page: nothing is sent anywhere.

Isometric Cloud Editor (MIT), built on @johnoscott/isometric-engine 0.14.1 (MIT).

Third-party software in this page: Lucide icons (ISC (some icons MIT, from Feather)), yaml (ISC), Monaco Editor (MIT), DOMPurify (Apache-2.0 OR MPL-2.0). The editor's and the engine's licences, and these notices: LICENSES.txt.
